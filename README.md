# BIMpool — sitio web

Landing corporativa de BIMpool (servicios BIM). Astro 7, sitio estático.

- Producción: https://bimpool-web.vercel.app
- Cada push a `main` despliega automáticamente en Vercel.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/
```

Ver `CLAUDE.md` para la estructura y los contenidos pendientes de reemplazar.
